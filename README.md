# Project Foundation

Основа для постепенного отделения Project Zomboid от его визуальной подсистемы: переносимый графический API, Vulkan-бэкенд, адаптер PZ и референсный мод под MIT.

Проект нужен, чтобы развивать рендер независимо от игровой логики и дать модам согласованный доступ к графическим ресурсам. Совместимость с обычными модами PZ — обязательная часть задачи. Основной путь на современных Mac — **KosmicKrisp → Metal 4**, Apple Silicon и macOS 26+.

**Сейчас это архитектура и компилируемый каркас модулей.** Vulkan не реализован, адаптер не подключается к игре, референсный мод не запускается. Совместимость с модами пока является требованием, а не подтверждённым результатом.

## Каркас

Модули и разрешённые зависимости заданы в [каталоге](architecture/modules.json). Из него Gradle строит граф проектов. Все Java-пакеты пока содержат только `package-info.java`: сигнатуры SDK не заморожены до исследования адаптера.

```text
foundation-api        foundation-runtime
platform-api          platform-glfw
graphics-api          graphics-runtime
graphics-vulkan       graphics-vulkan-interop
presentation          adapters/pz
mods/foundation-reference
tools/graphics-lab     tools/frame-replay
```

## Проверка

```sh
python3 tools/check_architecture.py
./gradlew check
```

Нужны Python 3.9+ и JDK 17+. На Windows: `gradlew.bat check -PpythonExecutable=python`.
Gradle Wrapper при первом запуске скачивает зафиксированную версию Gradle с проверкой SHA-256. Vulkan SDK, GPU и установленная PZ на этой стадии не нужны. Java 17 — уровень исходников каркаса, не обещание JVM-совместимости будущего адаптера с любым билдом игры.

## Совместимость

Обычным модам не потребуется переходить на новый SDK, если они используют поддерживаемые ванильные контракты. Lua-события, контент, UI, игровые данные и сетевое поведение должны сохраняться. Ванильные функции рисования обслуживает адаптер. Моды с прямыми OpenGL-вызовами, заменой рендера или приватными GPU-идентификаторами потребуют интеграции с Foundation. Подробности и границы обязательств — в [матрице совместимости](docs/mod-compatibility.md).
