# ADR 0004: управляемое владение GPU-работой

Дата: 2026-10-21. Статус: accepted.

## Контекст

Независимые графические моды могут конфликтовать по устройству, очередям, ресурсам и presentation. Неявное общее состояние воспроизвело бы прежние проблемы.

## Решение

Runtime владеет отправкой GPU-работы и presentation. Мод объявляет resources/access/order и добавляет graphics/compute/transfer-задачи. Portable API и Vulkan interop разделены. Native recording scope имеет ограниченное время жизни, объявленные ресурсы и заданные границы синхронизации. Заменяющие одну стадию providers согласуют эксклюзивное владение до запуска.

## Последствия

Обычные расширения не нуждаются в Vulkan-specific типах. Native-мод остаётся способен повредить процесс; sandbox не обещается. Независимые очереди, внешний submit и горячая перезагрузка Java откладываются до отдельных проверенных контрактов. Исключение после submit не вызывает попытку продолжить кадр через GL.
