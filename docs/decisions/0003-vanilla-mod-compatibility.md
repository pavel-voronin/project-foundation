# ADR 0003: обычные моды сохраняют ванильные контракты

Дата: 2026-10-21. Статус: accepted.

## Контекст

Обычные Lua/content/UI-моды — основная часть пользовательского опыта PZ. Требование перехода всего Workshop на Foundation сделало бы смену графики непригодной.

## Решение

Обычный мод продолжает использовать ванильные API без Foundation descriptor. Сохраняются Lua-события, assets/scripts, layout/input UI, ванильное рисование, данные мира и multiplayer-поведение. Перевод графических операций — ответственность адаптера. Совместимость проверяется вместе с каждой переносимой подсистемой и блокирует выпуск при подтверждённом регрессе.

Прямые GL-вызовы, GPU IDs и подмена внутренних renderer-классов требуют интеграции. Для собственного 3D-рендера предусмотрены providers и native interop. Полный OpenGL-эмулятор не планируется.

## Последствия

Требуется воспроизводимая [матрица модовых сценариев](../mod-compatibility.md). Состояния «требуется», «проверено», «не проверено» и «несовместимо» различаются. Совместимость со всем Workshop или произвольным Java override не обещается. Контракты игры сохраняются даже после удаления GL-реализации.
