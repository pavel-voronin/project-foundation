# `graphics-lab`

Самостоятельные контрольные сцены без установки PZ.

Статус: каркас. Исполняемой реализации нет. Публичные контракты — черновик.

Разрешённые зависимости: `foundation-runtime`, `graphics-runtime`, `graphics-vulkan`, `presentation`, `platform-glfw`.

Границы и владение описаны в [архитектуре](../../docs/architecture.md).
