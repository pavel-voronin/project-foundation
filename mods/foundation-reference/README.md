# `foundation-reference`

Будущая сборка штатного вида PZ; точка композиции компонентов.

Статус: каркас. Исполняемой реализации нет. Публичные контракты — черновик.

Разрешённые зависимости: `foundation-runtime`, `graphics-runtime`, `graphics-vulkan`, `presentation`, `platform-glfw`, `adapter-pz`.

Границы и владение описаны в [архитектуре](../../docs/architecture.md).
